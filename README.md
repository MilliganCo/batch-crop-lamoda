# Batch Product Image Cropper

Небольшая desktop-утилита на Python для пакетной подготовки товарных изображений: программа открывает выбранную папку, обрезает изображения по центру, приводит их к фиксированному размеру `1524x2200` и сохраняет результат в отдельный подкаталог.

## Статус аудита

Проект можно публиковать как generic image-processing utility после full-history scan и добавления sample images. В публичном позиционировании лучше не привязывать проект к конкретному бренду/площадке; код сам по себе универсален.

## Что делает

- выбирает исходную папку через `tkinter`;
- обрабатывает изображения `jpg`, `jpeg`, `png`, `tif`, `tiff`;
- масштабирует кадр с сохранением пропорций;
- делает центральный crop под целевой формат;
- пытается сохранить исходный ICC-профиль и привести изображение к `sRGB`;
- сохраняет результат в подкаталог `1524x2200`.

## Стек

- Python;
- Pillow;
- Tkinter;
- PyInstaller spec-файлы для сборки Windows-версии.

## Как запустить

```bash
python crop.py
```

## Перед публикацией

1. Выполнить full-history scan.
2. Добавить sample before/after images без коммерческих данных.
3. Добавить screenshot/GIF.
4. Проверить сборку `.exe`, если она заявляется.
