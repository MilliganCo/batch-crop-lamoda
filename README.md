# Batch Product Image Cropper

Локальная утилита для центральной обрезки товарных изображений до **1524 × 2200**.
Исходные файлы сохраняются; результат записывается в одноимённую подпапку.
Поддерживаются JPEG, PNG, TIFF. Повторный запуск перезаписывает файлы результатов.

## Установка и запуск

Нужны Python 3.10+ и Tkinter (в стандартной поставке Python для Windows).

```sh
python -m pip install -r requirements.txt
python crop.py
```

Выберите папку с изображениями. Программа масштабирует каждый кадр, обрезает его по центру
и сохраняет копию в `1524x2200/`. Ошибка одного файла не прерывает обработку остальных.

Если исходный ICC-профиль читается, пиксели переводятся в sRGB и получают профиль sRGB.
Если профиль отсутствует или повреждён, выполняется обычное преобразование в RGB без
добавления неподтверждённого профиля; при ошибке выводится предупреждение.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Тесты проверяют преобразование LAB → sRGB, размер результата, правильность ICC-тега и
изображения без профиля. Графический диалог и сборка EXE отдельно не проверялись.
PyInstaller `.spec`-файлы сохранены как заготовки сборки.
