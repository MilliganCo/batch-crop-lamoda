# Batch Crop Lamoda

## Описание

Небольшая desktop-утилита на Python для пакетной подготовки карточек товара: программа открывает выбранную папку, обрезает изображения по центру, приводит их к фиксированному размеру `1524x2200` и сохраняет результат в отдельный подкаталог.

## Что делает

- выбирает исходную папку через `tkinter`
- обрабатывает изображения `jpg`, `jpeg`, `png`, `tif`, `tiff`
- масштабирует кадр с сохранением пропорций
- делает центральный crop под целевой формат
- пытается сохранить исходный ICC-профиль и привести изображение к `sRGB`

## Стек

- Python
- Pillow
- tkinter
- PyInstaller spec-файлы для сборки Windows-версии

## Статус

Проект рабочий, но компактный: это специализированная утилита под конкретный сценарий подготовки изображений.

## Как запустить

```bash
python crop.py
```

После запуска нужно выбрать папку с изображениями. Результат будет сохранён в поддиректорию `1524x2200`.

## Примечание

В репозиторий не включаются собранные бинарники, виртуальное окружение и тяжёлые служебные артефакты.
